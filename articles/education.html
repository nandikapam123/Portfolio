Why these topics, in this order

Each topic is a vehicle for one core idea, and together they climb the layers of abstraction from circuits up to code.

TopicThe idea it carries
HTMLStructure and syntax; immediate visible feedback on every change
PythonControl flow, variables, functions; debugging as a normal step
Java and C++Types and the compile–run cycle; why languages differ
Digital circuitsBoolean logic and truth tables: how a decision is physically implemented
HardwareHow circuits become a computer, closing the loop with the code

What I try to teach beyond syntax

Breaking a problem into small steps, predicting what code will do before running it, and treating a bug as information. Those habits carry over to the engineering in the rest of this notebook, where the same discipline of stating a prediction and then checking it against evidence is what the figures are for.
